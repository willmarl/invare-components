Adjustable XL6009 boost/buck (HW-132) module that can step voltage up or down. Set the output with the trim pot and measure with a multimeter before connecting a load. Efficiency drops when input and output are far apart; it also gets hot under load.

- Input Voltage : 5V – 32V
- Output Voltage : 1.25V – 35V (adjustable)
- Practical Current : ~1.5A continuous (chip claims more, board/heat usually limits it)
