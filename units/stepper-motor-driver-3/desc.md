A4988 stepper driver carrier — step/dir control with microstepping. Set current with the onboard pot before connecting a motor (too high cooks the driver and motor). Put a heatsink on it. MS1/MS2/MS3 set microstep mode.

- Logic Voltage : 3V – 5.5V
- Load Voltage : 8V – 35V
- Current : ~1A without heatsink, up to ~2A with heatsink + cooling
- Microstepping : full, 1/2, 1/4, 1/8, 1/16
